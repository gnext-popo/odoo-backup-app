Privacy Policy – AWS Odoo Backup

Last updated: 2026-11-26

What this application does

AWS Odoo Backup is an internal tool used by Linklusion. It uploads Odoo database backup files from the company's Amazon S3 bucket to the company's own Google Drive account.

Google user data

The application requests only the drive.file scope. With this scope it can see and manage only the files and folders that it creates itself. It cannot read, change or delete any other file in Google Drive.

The application does not access any other Google account data (such as email, contacts or calendar).

Sharing

No data is collected, sold, or shared with third parties. Backup files stay in the company's own AWS account and Google Drive.
